# BG7BAG

Licensed amateur radio operator. Technical writer for radio and telecom.

I run [bg7bag.com](https://bg7bag.com) — free resources for radio operators: a worldwide repeater map, bilingual study question banks, rig guides, and operating tools.

## Projects

- **[bark-relay-worker](https://github.com/bg7bag/bark-relay-worker)** — a minimal Cloudflare Worker that forwards alerts to Bark (iOS push) with duplicate throttling. Deploy it to your own account with your own Bark key; a repeater watchdog, a DX spot filter, or a station monitor can then buzz your phone with one HTTP request.
